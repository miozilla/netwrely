# netwrely 🕸️🚦
netwrely : | Network Reliability Engineering | Network Intelligence, Flow Analyzer, Cloud Operations, Performance Alert, Data Exfiltration, Traffic Burst. SRE |


## Objectives
- Use Network Reliability Engineering approach to investigate a suspicious outbound traffic spike that may indicate data exfiltration
- Perform a historical root-cause analysis of the traffic surge
- Establish the nature of the issue by using Flow Analyzer to analyze custom time window
- Utilize filters to investigate traffic & analyze flow details
- Identify the specific VM instance responsible for traffic burst


## Similar Skills Set
- AWS : VPC Flow Logs + CloudWatch Logs Insights
- Azure : NSG Flow Logs + Traffic Analytics
